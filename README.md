# 🏥 Healthcare Analytics Dashboard

An interactive **Power BI Dashboard** developed to analyze healthcare data and provide meaningful insights into patient demographics, billing trends, medical conditions, doctor performance, and insurance providers.

---

## 📌 Project Overview

This dashboard helps healthcare organizations monitor key performance indicators (KPIs) and make data-driven decisions through interactive visualizations.

---

## 🎯 Objectives

- Analyze patient demographics
- Monitor billing trends
- Identify common medical conditions
- Evaluate doctor performance
- Analyze insurance provider distribution
- Understand patient age and gender distribution

---

## 🛠️ Tools & Technologies

- Power BI Desktop
- Microsoft Excel
- Power Query
- DAX (Data Analysis Expressions)

---

## 💡 Key Insights

- Total of **56K patients** analyzed.
- Hospital generated **₹1.42 Billion** in billing.
- Average patient stay is **16 days**.
- Arthritis and Diabetes are among the most common medical conditions.
- Male and Female patient distribution is nearly equal.
- Billing remained relatively stable over the years.
